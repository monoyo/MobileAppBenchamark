# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## MobileBenchmarkAppReactNative

React Native reimplementation of the Flutter Mobile Benchmark app. Uses Expo Router and Expo SDK. Android-ready.

Features mirrored:
- Home screen with launch-time measurement
- Benchmark Suite running 3 iterations of: UI, CPU, RAM, Image Loading, API, Location
- Results auto-saved to app documents directory as text

When you're ready, run:

```bash

```

This command will move the starter code to the **app-example** directory and create a blank **app** directory where you can start developing.
